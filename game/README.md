# Kingsday · 橙色奇遇

独立的手机 HTML5 游戏界面。此目录没有修改原始 `index.html` 或旧版 `mobile.html`。

## 玩法

- 2–6 个不同角色同局，随机抽取身份。
- 默认 1 名真人和 5 名 Bot。支持同一手机的多名真人轮流操作，空位补 Bot。
- 单人只展开自己的完整角色卡。其他玩家显示小头像和胜利进度，点击可看详情。
- 交易、拍照、供餐、围观等需要真人回应时，Bot 会暂停。
- 自动保存到当前浏览器，重新打开后可继续。没有跨设备同步或联网房间。

## 规则来源与边界

`engine.js` 的角色、20 张事件、资源、技能及胜利结算直接提取自原仓库逻辑版。其规则函数未经改写。新适配层收集原版手动界面的动作并分配给当前决定者。

Bot 使用原版自动策略，包括只抽卡与强对抗偏好。当原自动策略给出的动作不在原手动界面允许的选项中时，选择当前界面的有效选项，避免代替真人回应或非法拒绝。自动策略无抽卡资源时原来会跳过，新界面让 Bot 使用原本可选技能，结算仍由原规则完成。

游戏沿用原逻辑的规则细节与限制，不另行调整平衡数值。玩家可无限选择未产生进展的行动，与原版相同；不人为添加回合上限或改判胜负。

## 验证

- 27,708 次操作与原逻辑逐步对照，状态完全一致。
- 120 局 Bot 测试完成，共 9,921 次操作。
- 覆盖 66 种状态，检查邀请回应者归属及存档恢复。
- 原始测试脚本保存在当前任务的 `work/test-game.cjs`。

## 美术

角色图集由内置 ImageGen 生成。`characters.png` 为原始图集，`characters.jpg` 是网页用压缩版本；通过 CSS 取图，不需要外部图片服务。

提示词：三列两行的六角色头像图集，阿姆斯特丹国王节主题，Finn、游客、摊主、食物摊主、表演者、志愿者；精致故事书与策略卡牌插画风格，深青色背景、橙金色暖光、无文字，1536×1024。
